# Section 6 research, day 3: polite phrases, hair and grooming, clothes and sewing

Date: 2026-11-13. Method: Nkọwa okwu search pages saved as text (tools/fetch_sources.py), plus 3 web searches. Search snippets (not fetched pages) are marked as such.

Note on Nkọwa okwu search: English searches return loose matches (e.g. "beautiful" returns ògòrì "lady"; "mirror" returns ènyò "lens"). Searching by Igbo word works better. Homonyms: ncha (soap) vs ǹchá (all); ntụtụ (syringe) vs ntùtù (hair); akwa (cry) vs akwà (cloth); ndo (shade) vs ndo (sorry).
